## 걸린 것

**1. 한 요소에 콤마로 등장·퇴장 애니메이션을 같이 걸면 안 된다.**
`animation-name: fadeUp, panelout` 처럼 두면 **두 번째 애니메이션(from: opacity 1)의
backwards fill 이 지연 전부터 적용돼** 나중에 나올 판이 처음부터 보인다 — llm-next-word 의
2라운드 후보판이 1라운드 위에 겹쳐 보이는 것을 프로토 렌더에서 잡았다. **등장은 래퍼,
퇴장은 내용물**로 요소를 갈라 각각 애니메이션 하나씩만 건다.

**2. 애니메이션을 걸었으면 `.animated` 클래스(fill both·paused)를 반드시 붙인다.**
확률 막대 `<i>`·선택 링에 클래스를 빼먹었더니 fill-mode 가 none 이라 재생이 끝난 시각의
프레임에서 초기 상태(빈 막대)로 되돌아갔다. 프레임 스크럽 렌더에서는 재생 '이후'도
찍히므로 fill both 가 없으면 전부 유령이 된다.

**3. 한글 타이핑(steps) 폭은 실측한다.** "오늘도 고생 많으셨습니다. 내일 뵙" 19타를
15.6em 으로 어림했더니 실제 14.98em — resolve 에서 완성 어절 앞에 어색한 공백이 남았다.
Playwright 로 폭을 재서 15em 으로 맞추고, frozen·resolve phase 는 width:auto 로 풀었다.

**4. 분량 1차 실측 277.6s 로 하한(280s) 근처.** 규약대로 문장을 늘리지 않고 내용을
더했다(s3에 "예습 안에 인사말·보고서·뉴스가 있었다" 한 호흡, +58자) → 286.4s (4:46).
선희 +8% 실측 페이스는 표준값(6.4자/초)과 일치했다.

**5. (재확인) 기본 Node 14로는 안 된다** — nvm v22 로 실행. rest-api-lecture 기록의
함정 5·6(프로토 렌더와 본 빌드의 Chromium 경합)을 피해서 **프로토 검증을 빌드 시작 전에
전부 끝냈다.**
