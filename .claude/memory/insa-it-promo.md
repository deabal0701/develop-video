## 제작

13년 된 레거시 인사 시스템 H5 를 멀티테넌트 SaaS(insa-IT)로 **신규 개발**한 프로젝트의 홍보영상.
사용자 요청은 "5분 · 재미있게". 톤은 네 선택지 중 **유쾌한 해설** — 실제 수치를 농담의 재료로 쓰되
과장하지 않는 선이다. 의인화·리액션 같은 본격 예능 톤은 대외 보고에 부담이라 뺐다.

**구조 — 5분을 버티게 하는 챕터 척추.** 30초 홍보와 달리 5분은 이탈이 진짜 위협이라
`chapter.html` 4장으로 척추를 세우고 진행률 막대(20/45/68/88)를 노출했다.

```
훅(13년→취소선) → 레거시 수치 3연타 → intro → ch1 매일 여는 화면(s1~s4)
→ ch2 인사팀이 일하는 화면(s5~s7) → ch3 결재·급여(s8~s9)
→ ch4 멀티테넌시(s10~s12) → 목표치 stat → s13 정리 → outro
```

**훅은 컨셉 검증 워크플로에서 살아남은 것을 썼다.** 5안 병렬 생성 → 3관점 심사 결과,
"이 시스템 몇 년 됐을까요? → 13년 → (다음 컷) 1̶3̶년̶" 이 유일하게 훅으로 성립한다는 판정이었다.
숫자를 자랑이 아니라 **흉터**로 내놓는 각도. 클로징("13년을 버텨 준 시스템 위에 다음 13년을")이
그 취소선을 회수해 5분을 한 문장으로 묶는다.

**목소리**는 선희(edge). 유쾌한 해설 톤에 맞고 5분 내내 안 지친다. `rate +6%` — 기본 속도는
해설조로 느리고, 광고 기본값(+8%)은 5분에는 조급하다. eleven 은 무료 플랜이 보이스 라이브러리
목소리를 API 로 막아 사용 불가(check-tts 확인), azure 는 살아 있으나 edge 와 같은 선희라 실익 없음.

**정직성 장치 3개.** 홍보영상이지만 넘지 않은 선:
- 급여(s9)에서 "화면까지 나왔고 실제 연동은 다음 단계 과제입니다" 를 **내레이션에 명시**.
  보상관리는 퍼블리싱만 되어 있고 실연동은 Phase 2 다.
- KPI stat 카드에 "(목표치)" 를 박고 내레이션도 "이건 실적이 아니라 목표치입니다" 로 닫았다.
- 개발기간·투자금액·ROI·절감률·고객사 수·성능수치는 원본 문서에서 전부 TBD 라 **한 번도 안 썼다**.
