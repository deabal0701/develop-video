# assets/media : 산출물 공통 이미지 정본

| 파일 | 용도 | 상태 |
|---|---|---|
| `white-logo.png` | 회사 로고(화이트 정보통신). 표지 하단 + 각 페이지 바닥글 오른쪽 | 배치 완료. 218 × 51 px, 배경 투명 |

## 로고 요건

- 형식 PNG(배경 투명). 문서에서는 표지 170 × 40 px, 바닥글 84 × 20 px 로 축소해 사용한다. 더 높은 해상도의 원본이 확보되면 교체한다.
- 현행 자산의 가로세로비는 4.27 : 1 이다. 다른 비율의 원본으로 교체하면 `META.logo.coverWidth / coverHeight / footerWidth / footerHeight` 로 조정한다.
- 로고는 색 정책(검정·회색조)의 유일한 예외다. 원본 색을 그대로 쓴다.

## 사용

각 산출물의 `_build/media/` 로 복사한 뒤 `build.js` 의 `META.logo.file` 이 그 경로를 가리키게 한다.
파일이 없으면 로고 없이 생성되고 빌드는 성공하므로, 배포 전 체크리스트에서 로고 표시 여부를 확인한다.
