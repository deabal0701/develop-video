# insa-IT 산출물 docx 서식 규격 (수치 정본)

`assets/_build-template/engine.js` 의 상수와 1:1 대응한다. 값을 바꾸면 양쪽을 함께 고친다.
최종 서식은 `assets/styles.xml`(DEVELOPMENT-PLAN-v0.6.docx 동결 스냅샷)이 덮어쓰므로, engine 의 스타일 정의는 스타일 미적용 상태의 fallback 이다.

| 본문 폭 | **9740 DXA** (표·코드 블록 폭의 기준) |

## 3. 표

| 항목 | 값 |
|---|---|
| 테두리 | SINGLE size 4 / **BFBFBF** (4면) |
| 헤더 행 배경 | **D9D9D9** + bold (`cell({head:true})`) |
| 구분 열 배경 | **F2F2F2** (`cell({sub:true})`). 보통 첫 열 |
| 셀 여백 | 상하 50 / 좌우 110 |
| 셀 정렬 | 세로 가운데 |
| 폭 | `WidthType.DXA` 고정. **table 폭 = columnWidths 합 = 셀 width** |
| 페이지 넘김 | 헤더 행 반복(`tableHeader`) + 행 분할 금지(`cantSplit`) |
| 캡션 | **붙이지 않는다.** 표 제목은 앞 문단이나 절 제목이 대신한다. 번호·캡션은 그림에만 |

## 4. 그림

| 항목 | 값 |
|---|---|
| 배치 | 이미지(가운데) → 캡션(아래) → 필요 시 번호 설명표 |
| 캡션 | `그림 {장}-{순번}. 제목`. 9pt 이탤릭 가운데. 그림 **아래** |
| 번호 설명표 | 열 폭 `[900, 2600, 6240]` = `#` / 영역 / 설명. `#` 열은 가운데 정렬 |
| 묶음 헬퍼 | `figureWithLegend(file, caption, rows, {width,height})`. rows = `[{no, area, desc}]`. 이미지 안에 표시한 번호와 `#` 열이 1:1 대응 |
| 이미지 누락 | 파일이 없으면 `[이미지 없음: 파일명]` 테두리 상자를 남기고 콘솔에 경고. 배포 전 반드시 채운다 |
| 원본 위치 | `_build/media/` |

## 5. 코드 블록

- 1칸 표로 구현: 배경 **F5F5F5**, 테두리 BFBFBF, 셀 여백 상하 80 / 좌우 140.
- 한 줄이 한 Paragraph(`keepLines`), 폰트 Consolas 7.5pt.
- `code(\`...\`)` 로 템플릿 문자열을 그대로 넣는다(앞뒤 개행 자동 제거).
- 주석·출력 예시는 `#` 로 코드 안에 함께 둔다.

## 6. 강조 상자

강조 수단은 `notice(title, [lines])` **한 가지뿐**이다. 종류를 늘리지 않는다.

| 항목 | 값 |
|---|---|
| 모양 | 1칸 표. 배경 **FAFAFA**, 좌측 세로바 size 18 / 808080, 나머지 3면 size 4 / BFBFBF |
| 셀 여백 | 상하 120 / 좌우 180 |
| 제목 | **8.5pt** bold. **아이콘을 넣지 않는다.** 문장형 제목으로 쓴다 |
| 본문 | **8.5pt**, 줄간 276. 문단 여러 개 가능. 본문(9pt)보다 한 단계 작게 조판한다 |
| 쓰는 때 | 지키지 않으면 문제가 되는 규칙, 설계 판단의 근거. 한 문장으로 끝나는 내용은 본문 문단으로 쓴다 |

## 7. 표지

```
(빈 줄 7)
insa-IT(인사잇) {산출물군}          22pt bold, 가운데
<{주제}>                            18pt bold, 가운데
V{버전}                             12pt,     가운데
문서정보표 (폭 6400 / 2200+4200)     문서명 · 버전 · 작성 부서 · 작성일
{배포 구분}                          10pt bold, 가운데 (META.classification 이 있을 때만)
(빈 줄 8, 배포 구분이 있으면 6)
[회사 로고]                          기본 170 × 40 px, 가운데
화이트 정보통신 R&D 개발팀           12pt bold, 가운데
{연도}                              12pt,     가운데
(페이지 나눔)
```
표지에는 바닥글(쪽번호)을 넣지 않는다. `titlePage: true` + `footers.first` 비움으로 처리한다.

## 8. 변경 이력

- 표지 다음 페이지. 제목 '변경 이력'(16pt bold) + 4열 표.
- 열 폭 `[1500, 2200, 4440, 1600]` = 버전 · 일자 · 변경 내용 · 작성자.
- 버전 열은 `sub` 음영 + bold. 개정 시 행을 추가한다(기존 행 수정 금지).
- `META.version` 과 변경이력 마지막 행의 버전은 항상 일치한다.
- 버전 정책: `0.x` 초안, `1.0` 검수 확정본, `1.x` 내용 변경, `2.0` 서식·구조 개편.

## 9. 목차 · 그림 목차

- 목차: 변경 이력 다음 페이지. '목   차'(20pt bold, 가운데) + `TableOfContents`(hyperlink, headingStyleRange `1-3`).
- 그림 목차(옵션, `META.listOfCaptions = true`): 목차 다음 페이지. 제목 + 2열 표(`[8240, 1500]`, 제목 / 쪽). 표는 수록하지 않는다.
  쪽 번호는 캡션에 심은 책갈피를 `PAGEREF` 필드로 참조하므로 Word 필드 갱신 후 채워진다.
- 두 목차 모두 Word 필드다. 생성 직후에는 비어 있고 `build.ps1` 의 Word COM 갱신으로 채워진다.
  `-NoWord` 로 만든 파일은 배포하지 않는다.

## 10. 머리글 · 바닥글

| 위치 | 내용 |
|---|---|
| 바닥글(기본) | 가운데 `{현재} / {전체}` 8pt + 오른쪽 회사 로고(기본 84 × 20 px). `pageNumberTotal: false` 면 `- {현재} -` |
| 바닥글(표지) | 비움 |
| 머리글(옵션) | `{문서명}` 좌측, `{주제} V{버전}` 우측 + 하단 실선. `META.runningHeader = true` 일 때만 |

로고 배치는 `META.logo.on` 으로 정한다. `cover` / `footer` / `both`(기본).

## 11. 본문 문자 규칙

금지: 아이콘 기호 전반(`★` `☆` `✅` `✔` `⛔` `💡` `📌` 등, 딩벳·이모지 영역 전체) · `—`(em dash) `–`(en dash) · `─` `━` `═` `│`
허용: 가운뎃점 `·` · 화살표 `→` · 원문자 `①②③`

`check-text.py` 가 생성물의 표시 텍스트를 검사한다. `build.ps1` 이 스타일 적용 직후 자동 실행한다.
