익숙한 채팅 답변 타이핑이 문장 한가운데("내일 뵙…")서 얼어붙고 — "이 문장이 어떻게 끝날지,
챗GPT 자신도 모릅니다." 미리 써둔 답을 찾아오는 게 아니라 한 단어씩 만드는 중이라는 반전.
엔딩에서 멈춘 문장의 다음 단어를 **시청자가 스스로 예측**하게 하고 "방금 여러분이 한 것,
그게 LLM이 하는 일의 전부"로 회수한다.

## 도식으로 만들 것 (전부 신규 — projects/work5min-01/ 전용)

| 파일 | 그림이 져야 할 설명 | 기법 |
|---|---|---|
| `chat-freeze.html` | 무브랜드 채팅 타이핑 → 프리즈(탈색·커서만) → 유령 후보 단어 3개(막대만). `mode=resolve` 면 후보에서 하나가 선택돼 문장이 완성 | steps() 타이핑 + 고정 지연 키프레임 (rest-delete 선례). 훅·회수 두 번 사용 — 타이밍은 t params |
| `llm-promise.html` | 오늘 가져갈 세 항목이 차례로 서고 밑줄 | rest-line 의 이름표 패턴 |
| `llm-search-vs.html` | 좌: 서랍(문서함)에서 완성된 답장을 꺼냄 / 우: 빈 말풍선에 단어 블록이 하나씩 날아와 조립 | 좌우 대비 + 이동(translate) |
| `llm-next-word.html` | 미완성 문장 뒤 후보 3~4개가 확률 막대와 함께 → 최상위 선택 → 문장에 붙음 → 다음 후보판 — 2~3회 반복돼 보임 | 상태 변화(생성) + scaleX 막대 |
| `llm-training.html` | 문서 더미가 흘러 들어가고, 빈칸 문제를 맞히고 틀리며 다이얼(파라미터)이 조금씩 돌아감 → 숫자 각인(3,000억·1,750억) | 데이터 흐름 + 수치 카드(출처 있는 수치라 stat 자리) |
| `llm-recap.html` | ① 찾지 않고 만든다 ② 다음 단어 맞히기 ③ 방대한 예습 — 순서로 쌓임 | rest-outro 패턴 |

전부 `../../motion/_base.css`·`_params.js` 상대 참조, animation 단축 속성 금지,
가운데 정렬은 left/right:0 + text-align (fadeUp 이 transform 을 덮는 함정).
