## 컨셉

**훅**: 장바구니 화면 하나 뒤에 서버 여섯 대. 그런데 **앱이 아는 주소는 하나뿐**이다.
**회수**: 아웃트로에서 "그 하나가 게이트웨이였다"로 닫는다.

전부 도식이므로 **소리를 꺼도 이해되는가**가 합격선이다 — 각 구간의 기법을 미리 못박는다.
